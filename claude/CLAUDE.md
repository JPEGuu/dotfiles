# Claude Code グローバル設定

## 返答言語

すべての返答は**日本語**で行うこと。コードや技術的な識別子（変数名・関数名・ファイルパスなど）は英語のまま維持する。

## Gemini フォールバック

Gemini CLI（`gemini -p "..."`）の実行が失敗した場合（コマンドが見つからない・タイムアウト・エラー終了など）、Claude 自身が代わりにタスクを実行すること。その際、Gemini に委譲しようとしていた理由（大量コンテキスト・Web検索など）を踏まえ、可能な範囲で同等の結果を出すよう努める。

## ハルシネーション対策

以下のルールを**常に**適用すること：

- **不確実な場合は明示する**: 確信が持てない情報は「確認が必要です」「十分な情報がありません」と明示し、推測を事実として述べない
- **根拠を示す**: 事実に関する主張は、参照したファイル・行番号・URLなど具体的な出典を示す
- **提供情報に限定する**: ユーザーから渡されたファイル・コードのみを根拠にする。一般知識で補完する場合はその旨を明示する
- **複雑な推論は段階的に**: 結論を出す前に推論ステップを示し、誤った仮定を自己検出できるようにする

## TDD 絶対遵守

- RED → GREEN → REFACTOR のサイクルを厳守
- テストなしのコード変更は禁止
- REFACTOR 6項目（命名・責務・重複・複雑度・テスト品質・ドキュメント）を毎回チェック
- **適用範囲**: テスト可能なコード（src/ 配下のロジック）が対象。設定ファイルのみの変更、ドキュメント更新、データ分析スクリプト等は適用外

## 能動的行動原則

| レベル | 定義 | 例 |
|--------|------|-----|
| 🟢 自動実行 | 確認なしで即座に実行 | `git status`, CHANGELOG追記, TDDフロー遵守 |
| 🟡 提案→確認→実行 | 理由を説明し承認後に実行 | `/compact` 提案, SPEC作成提案 |
| 🔴 慎重実行 | 保全措置＋明示的確認を必須 | `/clear`, `git push`, 破壊的操作 |

**🟢 自動実行アクション:**

| トリガー | アクション |
|---------|-----------|
| セッション最初の発話 | `/user:session-start` を実行 |
| 実装を指示された | `/user:tdd-cycle` フローに従う |
| タスク完了時 | CHANGELOG.md に成果を追記 |
| 重要な設計判断をした時 | DECISIONS.md に D-NNN で追記 |
| セッション終了指示 | `/user:session-end` を実行 |

## コンテキスト管理

| 使用率 | Claude の行動 |
|--------|-------------|
| 0-50%  | 通常作業 |
| 50-70% | タスク完了後に `/clear` を検討提案 |
| 70-80% | 「⚠️ 70%超」と報告し `/compact` を提案 |
| 80%+   | 「🔴 80%超」と警告し `/clear` を慎重実行 |

## MCP vs CLI の使い分け原則

```
ツールが必要になった
  → CLI で同等の操作ができるか？
    → Yes → Bash 経由で CLI を使う
    → No  → MCP サーバーを有効化
```

| ツール | CLI利用（優先） | MCP利用（必要時のみ） |
|--------|----------------|-----------------|
| GitHub | `gh pr create`, `gh issue list` | — (CLIで十分) |
| Docker | `docker compose up` | — (CLIで十分) |
| データベース | `sqlite3`, `psql` | リアルタイム補完等が必要な場合 |
| Slack等 | — | 常時接続・監視が必要 ✅ |
