# Claude Code グローバル設定

## 返答言語

すべての返答は**日本語**で行うこと。コードや技術的な識別子（変数名・関数名・ファイルパスなど）は英語のまま維持する。

## Gemini フォールバック

Gemini CLI（`gemini -p "..."`）の実行が失敗した場合（コマンドが見つからない・タイムアウト・エラー終了など）、Claude 自身が代わりにタスクを実行すること。その際、Gemini に委譲しようとしていた理由（大量コンテキスト・Web検索など）を踏まえ、可能な範囲で同等の結果を出すよう努める。

## ハルシネーション対策

以下のルールを**常に**適用すること：

- **不確実な場合は明示する**: 確信が持てない情報は「確認が必要です」「十分な情報がありません」と明示し、推測を事実として述べない
- **根拠を示す**: 事実に関する主張は、参照したファイル・行番号・URLなど具体的な出典を示す
- **提供情報に限定する**: ユーザーから渡されたファイル・コードのみを根拠にする。一般知識で補完する場合はその旨を明示する
- **複雑な推論は段階的に**: 結論を出す前に推論ステップを示し、誤った仮定を自己検出できるようにする
