## テスト実行

対象ファイルが指定されている場合はそのファイルのテストを、指定がない場合は全テストを実行する。

結果を以下の形式でレポートする：

```
## テスト結果
- **ステータス**: PASSED / FAILED
- **合計**: N tests
- **失敗**: N tests（失敗した場合）

### 失敗したテスト（あれば）
- `test_xxx`: （エラーメッセージの要約）
```

失敗がある場合、原因と修正方針を提案する（/user:tdd-cycle フローに従う）。
