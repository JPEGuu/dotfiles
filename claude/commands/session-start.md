## セッション開始チェックリスト

### 1. ペルソナ・役割の確認
プロジェクトの `CLAUDE.md` が存在する場合、ペルソナ設定と役割分担を読み込む。

### 2. 引き継ぎファイルの確認
`.agents/handoff/gemini_to_claude.md` が存在する場合、内容を読み込んで前回の Gemini セッションからの引き継ぎ事項を把握する。

### 3. ドキュメント読み込み
`docs/` ディレクトリが存在する場合、主要な仕様ファイルを確認する。

### 4. リポジトリ状態の確認
```
git status
git log --oneline -5
```

### 5. テスト状態の確認
テストが存在する場合、現在の状態を確認する（実行はしない）。

### 6. サマリ報告
以下の形式で現状を報告する：

```
## セッション開始サマリ
- **引き継ぎ**: あり / なし
- **未コミット変更**: あり / なし
- **直近のコミット**: （コミットメッセージ）
- **今セッションの想定タスク**: （引き継ぎまたはユーザー指示に基づく）
```
