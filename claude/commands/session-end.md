## セッション終了チェックリスト

### 1. 変更内容の棚卸し
```
git diff --stat
git status
```
今セッションで変更したファイルと内容をリストアップする。

### 2. CHANGELOG.md への追記
`CHANGELOG.md` が存在する場合、以下の形式で今セッションの成果を追記する：

```markdown
## YYYY-MM-DD セッション成果

### 実装・修正
- （変更内容）

### 設計判断
- （あれば）
```

### 3. docs/ との同期確認
`docs/` ディレクトリが存在する場合、実装と仕様書にズレがないか確認する。
ズレがあれば指摘する（自動修正は行わない）。

### 4. 未コミット変更の確認
未コミットの変更がある場合、ユーザーにコミットを促す。

### 5. 最終報告
```
## セッション終了サマリ
- **変更ファイル数**: N 件
- **CHANGELOG**: 更新済み / 該当なし
- **未コミット**: あり / なし
```
