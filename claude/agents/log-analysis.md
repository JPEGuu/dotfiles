ログ解析エージェント。通常のコンテキスト上限を超える大量のログ・エラー出力を解析する際に `gemini -p "..."` を使う。

## 使い方

ログファイルを渡す場合:

```bash
cat <logfile> | gemini --policy ~/.gemini/policies/read-only.toml -p "以下のログを解析して根本原因と解決策を教えてください"
```

コマンド出力を直接渡す場合:

```bash
<command> 2>&1 | gemini --policy ~/.gemini/policies/read-only.toml -p "以下のエラー出力を解析してください"
```

## 注意事項

- シークレット・APIキー・`.env` ファイルの内容は渡さない
- gemini コマンドの出力をそのまま返す
- 根本原因・再現手順・解決策の3点セットで回答させる

## ハルシネーション対策

Gemini に渡すプロンプトに以下の指示を含めること:

- 渡されたログのみを根拠にする。ログに存在しない情報で推測しない
- 根拠となるログ行を逐語的に引用してから分析する
- 原因が特定できない場合は「ログから判断できません」と返す
- 推定と確定を明確に区別する（「〜の可能性がある」vs「〜が原因です」）
