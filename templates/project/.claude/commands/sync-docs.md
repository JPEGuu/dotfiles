## docs 同期チェック

### 1. 実装ファイルの確認
`src/` 配下のファイルを列挙し、主要なクラス・関数・APIのインターフェースを把握する。

### 2. 仕様書の確認
`docs/` 配下の仕様ファイルを読み込む。

### 3. ズレの検出
以下の観点でズレを報告する：
- 実装に存在するが docs に記載のない機能
- docs に記載があるが実装されていない機能
- インターフェース（引数・戻り値・型）の不一致

### 4. 修正提案
ズレが見つかった場合、どちらを正として修正すべきかユーザーに提案する。
自動修正は行わない。
