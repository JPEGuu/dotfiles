# Claude Code グローバル設定

## 返答言語

すべての返答は**日本語**で行うこと。コードや技術的な識別子（変数名・関数名・ファイルパスなど）は英語のまま維持する。

## エージェントのモデル選択

各エージェントのモデルは `~/.claude/agents/<name>.md` のフロントマター `model:` で静的に指定する。CLAUDE.md のルールはモデルを動的に上書きしない。

難易度ごとに2種類のエージェントを用意している場合は、以下の基準で使い分けること：

- **opus 版を使う条件**：新規パターンの考案、複数の競合する制約、ドメイン知識が必要な判断、トレードオフが自明でない意思決定
- **sonnet 版を使う条件**：既存パターンへの追加・拡張、要件・設計方針が概ね明確、既存コードを参考にできる
- **haiku 版を使う条件**：単一ファイルの定型的な変更、検索・読み込みのみで完結、判断を要しないコード生成

判断に迷う場合は低コスト側から試み、コンテキストが不足すれば上位モデルに切り替える。

## ハルシネーション対策

以下のルールを**常に**適用すること：

- **不確実な場合は明示する**: 確信が持てない情報は「確認が必要です」「十分な情報がありません」と明示し、推測を事実として述べない
- **根拠を示す**: 事実に関する主張は、参照したファイル・行番号・URLなど具体的な出典を示す
- **提供情報に限定する**: ユーザーから渡されたファイル・コードのみを根拠にする。一般知識で補完する場合はその旨を明示する
- **複雑な推論は段階的に**: 結論を出す前に推論ステップを示し、誤った仮定を自己検出できるようにする
