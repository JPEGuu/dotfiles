## セッション終了チェックリスト

### 1. 変更内容の棚卸し
```
git diff --stat
git status
```
今セッションで変更したファイルと内容をリストアップする。

### 2. CHANGELOG.md への追記
`CHANGELOG.md` が存在する場合、以下の形式で今セッションの成果を追記する：

```markdown
## YYYY-MM-DD セッション成果

### 実装・修正
- （変更内容）

### 設計判断
- （あれば）
```

### 3. docs/ との同期確認
`docs/` ディレクトリが存在する場合、実装と仕様書にズレがないか確認する。
ズレがあれば指摘する（自動修正は行わない）。

### 4. 未コミット変更の確認
未コミットの変更がある場合、ユーザーにコミットを促す。

### 5. 引き継ぎファイルの生成（Gemini へ）
`.agents/handoff/` ディレクトリが存在する場合、`claude_to_gemini.md` を上書きする：

```markdown
# Claude から Gemini への引き継ぎ事項

**日時**: YYYY-MM-DD
**宛先**: Gemini
**送信元**: Claude

## 1. 本セッションの成果
<!-- 今回やったことを簡潔に -->

## 2. 現在のシステム状態
| 項目 | 状態 |
|------|------|
| テスト | passed / failed |
| 主要な変更 | — |

## 3. Gemini へのお願い
<!-- 設計レビュー、仕様追加、方針決定など -->

## 4. 注意事項
<!-- 既知の問題、制約事項など -->
```

### 6. 最終報告
```
## セッション終了サマリ
- **変更ファイル数**: N 件
- **CHANGELOG**: 更新済み / 該当なし
- **引き継ぎ**: 作成済み / 該当なし
- **未コミット**: あり / なし
```
